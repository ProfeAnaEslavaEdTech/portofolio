## Cómo está organizado el CV (y por qué)

La convocatoria puntúa así:

| Apartado | Peso |
|---|---|
| Expediente académico | **70 %** |
| Premio extraordinario de licenciatura o grado | 5 % |
| Premio extraordinario de máster | 5 % |
| Realización de un segundo máster | 5 % |
| Conocimiento de idiomas diferentes a los de las titulaciones previas | 5 % |
| Consecución de becas | 5 % |
| Experiencia profesional en el ámbito del doctorado | 5 % |

El CV reproduce **exactamente ese orden y esa redacción**, de modo que la comisión pueda puntuar apartado por apartado sin buscar nada. Cada mérito lleva su código **[DOC-nn]**, que corresponde al orden del PDF de documentación acreditativa (`03-anexos/`).
